# Regras do Projeto — Portfólio de Dublagem & Voice Acting

- Site de portfólio profissional para Voice Actor em HTML, CSS e JavaScript puro (sem frameworks).
- Antes de criar ou alterar qualquer código, leia `referencias.md`, `identidade.md` e `funcionalidades.md`.
- Mantenha o código organizado: um arquivo CSS (`styles.css`), um JS (`script.js`), e o HTML (`index.html`) com marcação semântica focada em mídia acessível e players de áudio/vídeo.
- Evite templates genéricos: o layout deve parecer o portfólio de um dublador de destaque no mercado audiovisual de animes, jogos e séries.
- O site deve ser 100% responsivo (otimizado para diretores de dublagem, estúdios e fãs navegarem bem no celular e no computador).
- As imagens dos personagens devem usar links de imagem externos/web e tags `<img>` apropriadas com proporção mantida (object-fit: cover).
- Após cada entrega de código, explique em 2 a 3 linhas o que foi feito e como isso atende às necessidades da carreira de dublagem.
